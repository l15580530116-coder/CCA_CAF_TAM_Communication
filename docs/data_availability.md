# Data Availability

## No Raw Data Included

This repository contains only analysis scripts and gene set definitions. Raw and processed data files are excluded due to size and database redistribution policies.

## Processed Tables

Key processed tables (DEG results, ssGSEA scores, CellChat LR pairs, etc.) are available from the corresponding authors upon reasonable request and will be deposited in a public repository upon manuscript acceptance.
