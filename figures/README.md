# Figures

Main and supplementary figures are generated by scripts in `../scripts/`.

Key figure-generation scripts:
- `19_generate_figure1_workflow.py` — Figure 1 workflow schematic
- `30_assemble_composite_figures_2_7.py` — Figures 2–7 composite assembly
- `36_generate_supplementary_v2.py`, `36c_polish_supplementary_v3.py` — Supplementary figures S1–S10
- `38d_generate_main_figures_v5.py`, `38e_repair_figure7_v6.py` — Main figure expansion and repair

Individual panel PDFs are generated by R analysis scripts (06–18) and written to `figures/DEG/`, `figures/gsva/`, `figures/single_cell/`, etc.

Final composite figures are available in the submission package.
